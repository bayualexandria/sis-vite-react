# FrontEnd Sistem Informasi Siswa

Sistem informasi siswa ini berbasis Vite-React untuk keperluan user interface, untuk backend nya saya menggunakan golang untuk REST API nya [link golang](https://github.com/bayualexandria/rest-api-golang-sis):

Jalankan perintah ini untuk mendownload pacakge pada node_modules

```
npm install

```
##### Note:
Jika perintah diatas tidak bisa dijalankan anda harus menginstall nodejs di perangkat Leptop/PC.

Jalankan perintah ini untuk menjalakan program aplikasinya

```
npm run dev

```

Jalankan perintah ini untuk mendeploy-nya ke Ngix/Xampp/Lampp ect.

```
npm run build

```
Nanti akan muncul folder "dist". Itu adalah hasil build dan siap untuk di deploy ke web server.
